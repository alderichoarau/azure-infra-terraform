# terraform-shared-plan

Shared App Service Plan (`plan-npr-prf2026`) for the whole cohort — **trainer-side
only**. Students never apply this; they reference it via a read-only data source
(`data "azurerm_service_plan" "shared"`) in `../terraform-python` and
`../terraform-managed-services`.

Sibling of `../terraform-shared-aks/` (the mutualised AKS cluster) — same
`rg-shared-prf2026`, same "trainer applies once, students only read" idea, but
deliberately a **separate state**. This Plan needs to stay up continuously
(every learner's Python App Service, Function App and Java Web App run on it),
while the AKS cluster is the repo's most expensive resource and gets torn
down/recreated between AKS-track sessions — the two must never be forced to
live or die together. (This repo briefly merged them into one `terraform-shared/`
directory; it was split back apart for exactly this reason.)

## Who runs this, and when

You (the trainer), rarely: once per cohort to stand it up, and left running —
unlike `../terraform-shared-aks/`, there's no cost-driven reason to destroy this
between sessions.

## First-time setup

1. Create the HCP Terraform Cloud workspace `azure-shared-plan-prf2026` in the
   `alderic-hoarau` org (UI, or let `terraform init` offer to create it). Set
   its Execution Mode to **Local** (see `backend.tf`'s comment for why).
2. Either:
   - **Via GitHub Actions**: run the "Terraform Deploy" workflow
     (`.github/workflows/deploy-terraform.yml`), `directories=terraform-shared-plan`,
     `action=apply`. Reuses this repo's existing `AZURE_CLIENT_ID`/`AZURE_TENANT_ID`/
     `AZURE_SUBSCRIPTION_ID`/`TF_API_TOKEN` secrets.
   - **Locally**: `az login` with an identity that has Contributor (or
     better) on `rg-shared-prf2026`, then `terraform init && terraform plan`
     — review, then `terraform apply`.

## After applying

Nothing further needed — `../terraform-python` and `../terraform-managed-services`
both look this plan up by name (`shared_rg_name`/`shared_plan_name` vars,
defaults matching this directory's `shared_rg_name`/`plan_name`), no output
value needs copying anywhere.
