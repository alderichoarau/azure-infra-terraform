# terraform-python

TP observabilité Python: App Service + Function App + Container Instance +
Log Analytics/Application Insights/availability tests/alerts.

Depends on `../terraform-core` (VNet, shared Storage Account — read via
`terraform_remote_state`, see `main.tf`) and `../terraform-shared-plan` (the
App Service Plan, looked up by name via a data source — no state coupling).
Apply `terraform-core` first.

Independent of `../terraform-managed-services` and `../terraform-aks-app` —
this track can be applied, destroyed, or left off entirely without touching
either of the other two, and vice versa.

## Setup

1. `../terraform-core` must already be applied.
2. Create the HCP Terraform Cloud workspace `azure-python-alderic-hoarau`,
   Execution Mode **Local**.
3. `terraform init && terraform plan` — review, then `terraform apply`.

## Consumed by

`../terraform-prometheus` reads `app_service_hostname` and `action_group_id`
via `terraform_remote_state` (its `main_workspace_name` var — update it from
the old `azure-infra-alderic-hoarau` to `azure-python-alderic-hoarau` if not
already done).
